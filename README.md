A tiny Node program that writes one short, steadying text — snow falling on a field nobody is crossing, each flake landing exactly once — to /output/entry.txt for make.fun's relaxation-judge bounty. The passage is composed from named fragments, hard-gated to 1–280 characters, and written deterministically.

## Run it

```sh
node main.ts
```
